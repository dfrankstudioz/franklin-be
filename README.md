# Franklin BE — Builder’s Edition  
Local-first AI middleware for developers, homelabbers, and builders.

Franklin BE is a privacy-first AI engine that runs entirely on your machine.  
It combines a FastAPI backend, a compact Web UI, local tools, and optional TinyLlama/GPT-4o routing to create a file-centric AI assistant that never uploads your data unless you explicitly allow it.

## 🚀 Features
- Local-first AI
- FastAPI backend (Dockerized)
- Smart tool routing & TinyLlama support
- Modern Web UI
- Plugin-ready architecture
- Runs anywhere with Docker

## 📦 Installation
```bash
git clone https://github.com/dfrankstudioz/franklin-be.git
cd franklin-be
docker compose up -d
```
