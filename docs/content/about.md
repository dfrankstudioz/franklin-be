# About Franklin

Franklin — A Local-First AI Engine Built for Real Work

Franklin is a local-first AI middleware system designed to give you control, privacy, and power — without relying on the cloud. It runs entirely on your machine using Docker, a FastAPI backend, and optional local LLMs like TinyLlama. Franklin combines smart prompt routing, real tools, and a clean web interface to create a private AI workstation that actually gets things done.

---

## What Franklin Is (and Isn’t)
- Franklin isn’t a website.
- Franklin isn’t a chatbot.
- Franklin is a local AI operating layer for your files, tools, automations, and daily workflow.

---

## Key Principles

### Privacy by Design
Everything you do in Franklin stays on your machine. File access, summaries, memory, and tools run locally — no uploads, no external processing, and no hidden analytics. You decide when (or if) to use GPT-4o.

### Local-First & Practical
Franklin is built for people who want AI power without giving up control: builders, homelabbers, developers, automation fans, and privacy-minded users.

---

## How Franklin Works

- Local Tools  
  Franklin can list, read, and summarize files directly from your filesystem using real Python tools.

- Smart Prompt Routing  
  Natural-language requests are automatically routed to a local tool, a local LLM (e.g., TinyLlama), or a GPT-4o fallback depending on what you ask.

- Clean Web UI  
  A simple, fast React UI provides a chat window, tool panel, file selector, settings, and history — everything stays local inside your network.

- Fully Dockerized  
  Runs consistently on Linux, Windows, macOS, servers, homelabs, and laptops.

- Modular & Extensible  
  Add plugins, attach new tools, build dashboards (LifeOS, NOC Dash), or extend the system with custom scripts and automations. The philosophy: your machine is the platform; Franklin is the operator.

---

## The Vision
Franklin is the foundation for a larger ecosystem: a personal Life OS, home server dashboards, plugin-powered automations, local models, hybrid AI workflows, multi-device mesh networking, and zero-cloud dependency. It’s intended to be your AI infrastructure — not another cloud account.

---

## Why Franklin Exists
Most AI tools require you to upload data to the cloud. Franklin takes the opposite approach: everything local, everything private, everything under your control. It makes your computer smarter — without handing your life to someone else’s server.
