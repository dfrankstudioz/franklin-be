ABOUT FRANKLIN
Franklin — A Local-First AI Engine Built for Real Work
A local-first AI middleware system designed for control, privacy, and practical workflows.
Franklin is a local-first AI middleware system designed to give you control, privacy, and power — without relying on the cloud. It runs entirely on your machine using Docker, a fast FastAPI backend, and optional local LLMs like TinyLlama. Franklin combines smart prompt routing, real tools, and a clean web interface to create a private AI workstation that actually gets things done.
Franklin isn’t a website. Franklin isn’t a chatbot.
Franklin is a local AI operating layer for your files, tools, automations, and daily workflow.
Privacy by Design
Everything you do in Franklin stays on your machine. All file access, summaries, memory, and tools run locally — no uploads, no external processing, no hidden analytics. You choose when (or if) GPT-4o is used. Franklin was built for people who want AI power without giving up control.
How Franklin Works
Local Tools
Franklin can list, read, and summarize files directly from your filesystem using real Python tools.
Smart Prompt Routing
Natural-language requests are automatically routed to either a local tool, a local LLM (TinyLlama), or a GPT-4o fallback depending on what you ask.
Clean Web UI
A simple, fast React UI gives you a chat window, tool panel, file selector, settings, and history. Everything stays local inside your network.
Fully Dockerized
Franklin runs the same way on Linux, Windows, macOS, servers, homelabs, and laptops.
Modular and Extensible
Franklin is built to grow with you. Add plugins, attach new tools, build dashboards (LifeOS, NOC Dash), or extend the system with custom scripts and automations. The philosophy is simple: your machine becomes the platform, Franklin becomes the operator.
Why Franklin Exists
Most AI tools require you to upload your data to the cloud. Franklin takes the opposite approach: everything local, everything private, everything under your control. It’s built for builders, homelabbers, developers, automation fans, and privacy-minded users. Franklin makes your computer smarter — without handing your life to someone else’s server.
The Vision
Franklin is the foundation for a bigger ecosystem: a personal Life OS, a home server dashboard, plugin-powered automations, local models, hybrid AI workflows, multi-device mesh networking, and zero-cloud dependency. It’s your AI infrastructure, not another cloud account.
Built by One Person
Franklin was built from the ground up by a single creator — evenings, weekends, and spare moments — driven by the belief that powerful AI should be private, local, and accessible to everyday people.
About the creator
