# Getting Started

Your first steps with Franklin — simple, private, and local. Follow these minimal steps and you'll be up and running in minutes.

## 1️⃣ What you need
Make sure you have:
- A computer or server that can run Docker
- Docker installed and running
- A web browser (Chrome, Edge, Firefox, Safari, etc.)

That's it — no cloud accounts required.

## 2️⃣ Install Franklin
Franklin runs through Docker. Typical flow (exact steps are provided with your download/license email):
1. Download Franklin
2. Pull the Docker images
3. Start the Franklin container

Most users are up and running in under five minutes.

## 3️⃣ Open the Web UI
After the container starts, open your browser and visit:
- Local machine: http://localhost:9006
- Another device on your network: http://YOUR-SERVER-IP:9006

You’ll see the Franklin interface — a clean chat window with a tools sidebar.

## 4️⃣ Enter your license key
In the Web UI go to Settings → License, paste your license key, and click **Activate**.  
If you lose your key, email: support@dfrankstudioz.com

## 5️⃣ Try your first commands
Franklin understands plain English. Example prompts you can type into the chat:
- "What's in the memory folder?"
- "Read sample.txt"
- "Summarize notes.txt"
- "List my files."

Franklin will route your request to the appropriate tool or model automatically.

## 6️⃣ Local-only mode
To run fully offline: go to Settings → Enable Local Only Mode.  
Franklin will use your local TinyLlama model and will not send data to GPT or other cloud services.

## 7️⃣ Using Franklin on other devices
If Franklin is running on a server, access it from any device on your network (phone, laptop, tablet, another PC) via:
- http://SERVER-IP:9006

No cloud accounts, no central logins — everything stays local.

## 8️⃣ Need help?
Support options:
- Docs: Basic setup + reference (link available in the UI)
- Discord: Community help
- Email: support@dfrankstudioz.com

## 9️⃣ What’s next?
When you're comfortable, explore the Tools panel, read & summarize files, experiment with local-only mode, connect from another device, and join the community to share ideas. Franklin grows with you — one step at a time.

Tip: If you recently updated and something looks off, rebuild the Docker containers and restart Franklin — that resolves most update-related issues.
