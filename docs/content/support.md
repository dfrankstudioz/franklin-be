# Support

Simple, clear help for getting the most out of Franklin.

Franklin is designed to run locally, stay private, and be easy to use — but every system is different. This page points you to the straightforward places to get help.

---

## Quick Help
If you're having trouble, check these first — they resolve most first-time issues:
- Docker is installed and running
- Franklin containers are up
- No red errors in your terminal
- You can reach the Web UI at:
  - http://localhost:9006
  - or http://YOUR-SERVER-IP:9006
- After updates, rebuild the containers to apply changes

These steps fix the majority of setup problems.

---

## Common Troubleshooting
Most issues fall into a few categories:
- Franklin not starting
- Web UI not loading
- Tools (list/read/summarize) not responding
- Local model not detected
- GPT fallback returning errors

Typical causes:
- Service misconfiguration
- Environment variables missing or incorrect
- Docker network issues

Action: Check the logs for the failing service and verify relevant environment variables and network settings.

## Licensing Basics
- Enter your license key in the Web UI (Settings → License).  
- Lost keys can be re-sent—email support@dfrankstudioz.com.  
- Reinstalling the app won’t break your key.  
- Upgrades usually don’t require a new key.

## Running Franklin on a Server
Franklin runs anywhere Docker runs:
- Debian / Ubuntu
- Homelab servers
- TrueNAS (Docker-enabled)
- Proxmox containers
- Remote/local machines accessed over the network

Access from any device on your network via:
- http://SERVER-IP:9006

No cloud accounts or central logins — everything stays local.
