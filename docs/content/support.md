SUPPORT
Simple, clear help for getting the most out of Franklin
Franklin is designed to run locally, stay private, and be easy to use — but every system is different. This page points you to the straightforward places to get help.
Quick Help
If you're having trouble, check these areas first — they resolve most first-time issues:
Docker is installed and running
Franklin containers are up
No red errors in your terminal
You can reach the Web UI at
http://localhost:9006
or your server’s IP
After updates, rebuild the containers to apply changes
These steps fix the majority of setup problems.
Common Troubleshooting
Most issues fall into a few simple categories:
Franklin not starting
Web UI not loading
Tools (list/read/summarize) not responding
Local model not detected
GPT fallback returning errors
These are usually caused by service configuration or environment setup — check logs for the service that's failing and verify environment variables and Docker network settings.
Licensing Basics
Enter your license key in the Web UI settings
Lost keys can be re-sent
Reinstallation won’t break your key
Upgrades usually don’t require a new key
Straightforward and easy.
Running Franklin on a Server
Franklin works on anything that can run Docker:
Debian / Ubuntu
Homelab servers
TrueNAS (Docker-enabled setups)
Proxmox containers
Local machines accessed remotely
You can access Franklin from your phone, tablet, or laptop — anything on your network.
