## 🐋 Quick Install (Docker)

```bash
git clone https://github.com/dfrankstudioz/franklin-be.git
cd franklin-be
docker compose up -d
```

After the containers start successfully, open:

👉 **http://localhost:9006**

---

## 🎛 System Requirements

- Linux, macOS, or Windows  
- Docker + Docker Compose  
- 4GB+ RAM (8GB recommended)  
- 2GB disk space  

---

## 🔄 Updating Franklin

```bash
cd franklin-be
git pull
docker compose down
docker compose up -d --build
```
