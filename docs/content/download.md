## 🐋 Quick Install (Docker)

```bash
git clone https://github.com/dfrankstudioz/franklin-be.git
cd franklin-be
docker compose up -d
```

After the containers start successfully, open:

👉 **http://localhost:9006**

---

## 🎛 System Requirements

- **Operating System:**  
  Linux, macOS, or Windows
- **Runtime:**  
  Docker + Docker Compose
- **CPU:**  
  Any modern CPU; local models require more  
- **RAM:**  
  4GB+ (8GB+ recommended)
- **Disk:**  
  2GB free minimum

---

## 🔄 Updating Franklin

To update from a previous version:

```bash
cd franklin-be
git pull
docker compose down
docker compose up -d --build
```

Or download the new ZIP from GitHub Releases.
